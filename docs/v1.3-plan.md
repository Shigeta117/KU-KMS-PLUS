## v1.2.2 — Realtime 過剰発火バグ修正

### 問題

`useAssignments.ts` の Realtime サブスクリプションに `user_id` フィルタがない。
誰かが assignments を更新するたびに **全ユーザーの PWA が `fetchAssignments()` を呼ぶ**。

- データ漏洩なし（RLS が保護）
- ただし 100 ユーザー × 1 回の UPSERT = 100 DB SELECT が発生
- Supabase 無料枠（月 500 万行 READ）の早期枯渇リスク

### 修正内容

**`nextjs-app/lib/useAssignments.ts`**

```typescript
// 修正前
supabase
  .channel('assignments-realtime')
  .on('postgres_changes', { event: '*', schema: 'public', table: 'assignments' }, () => {
    loadData();
  })

// 修正後: 自分の user_id に限定
const { data: { user } } = await supabase.auth.getUser();
supabase
  .channel(`assignments-user-${user.id}`)
  .on('postgres_changes', {
    event: '*',
    schema: 'public',
    table: 'assignments',
    filter: `user_id=eq.${user.id}`,
  }, () => {
    loadData();
  })
```

### 影響範囲

- `nextjs-app/lib/useAssignments.ts` のみ

## v1.3.0 — メモ機能 + ラベル整理

### 背景

- 課題ごとに進捗メモ（「部分提出済」「後でやる」など）を残したい
- Web ダッシュボードと LMS ページ（Chrome 拡張）の両方で参照・編集できること
- 「非表示」はユーザーに意図が伝わらないため「スキップ」に改名

### DB スキーマ変更

Supabase ダッシュボードで手動追加（または SQL 実行）:

```sql
ALTER TABLE assignments ADD COLUMN note TEXT DEFAULT NULL;
```

- RLS ポリシーは変更不要（`user_id` 条件が既にある）
- UPSERT ペイロードに `note` は含めない → スクレイプ時に既存メモは上書きされない（`is_completed_manual` / `is_hidden` と同方式）

### nextjs-app の変更

#### `lib/types.ts`
- `Assignment` インターフェースに `note: string | null` を追加

#### `lib/supabase.ts`
- `fetchAssignments()` の select カラムリストに `note` を追加
- `updateAssignment()` の patch 型に `note` を追加

```typescript
// 修正後の型
type AssignmentPatch = Partial<
  Pick<Assignment, 'is_completed_manual' | 'is_hidden' | 'note'>
>;
```

#### `lib/useAssignments.ts`
- `handleUpdateNote(id: string, note: string)` を追加（デバウンス 800ms で保存）

#### `components/TaskCard.tsx`
- カード下部にメモエリアを追加
  - メモなし: 薄い「+ メモを追加」ボタン（タップで編集モード）
  - メモあり: テキスト表示 + タップで編集モード
  - 編集モード: `<textarea>` でインライン編集、フォーカスアウトで自動保存
  - 保存中: 保存インジケーター表示

#### `app/app/page.tsx` / `components/FilterBar.tsx`
- 「非表示」→「スキップ」ラベル変更（FilterBar の TABS 定義）
- EmptyState のメッセージ更新

### Chrome 拡張の変更

#### `background.js`
- `UPDATE_ASSIGNMENT` メッセージハンドラの `ALLOWED` セットに `'note'` を追加
- `updateAssignment()` 関数を `note` 対応に（フィールド名ホワイトリストで対応済みのため最小変更）

#### `content.js`

**`injectActionButtons()`**: ボタンバーの下にメモ入力行を追加
- プレースホルダー「メモ…」のテキストフィールド
- フォーカスアウトで background.js 経由で PATCH

**`applyDBStatesToPage()`**: `note` がある場合、課題ブロックのアクションバー上部に小テキストで表示

**ラベル変更**: `makeLmsBtn('非表示', ...)` → `makeLmsBtn('スキップ', ...)`

## v1.3.1 — PC / タブレットレスポンシブ刷新

### 方針

- **モバイル（〜767px）**: 現状を維持（変更なし）
- **タブレット・PC（768px〜）**: `md:` ブレークポイントで 2 カラムレイアウト

### ダッシュボード (`app/app/page.tsx` + `components/FilterBar.tsx`)

```
モバイル（現状維持）
[Header        ]
[FilterBar     ]
[TaskList      ]

PC / タブレット（新レイアウト）
[Header              (full width)       ]
[Sidebar  | TaskList                    ]
 w-64 固定   flex-1
 ├ タブナビ
 ├ 授業フィルタ
 └ カテゴリ
```

**`FilterBar.tsx` の変更**:
- `md:` 以上: sticky サイドバー（縦並びタブリスト）
- モバイル: 現状の横スクロールタブ・フィルタ行（変更なし）

**`app/app/page.tsx` の変更**:
- `md:flex md:flex-row` で親コンテナを flex 化
- `FilterBar` を左カラム (`md:w-64 md:flex-shrink-0`) に
- タスクリスト右カラム (`md:flex-1`)
- ヘッダーのパディング・フォントサイズを `md:` で微調整

### 設定ページ (`settings/page.tsx`)

- `md:grid md:grid-cols-2 md:gap-4` でセクションを 2 カラム配置
- `md:max-w-4xl` に最大幅を拡大（現状 `sm:max-w-2xl`）
- ブックマークレットセクションは colspan:2 で全幅
